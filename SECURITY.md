# Security Policy

## Supported Versions

Currently, only the latest version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  |  ✅                |
| older   |  ❌                |

## Reporting a Vulnerability

We take the security of NEXTGEN seriously. If you discover a security vulnerability, please **DO NOT** open a public issue.

Instead, please responsibly disclose the vulnerability by sending an DM to the core maintainers (@idontdocybersecurity or @majestic_728) in discord.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. Once the issue is resolved, we will publish a security advisory and credit you for the discovery.
